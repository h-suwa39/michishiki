# みちしき — アプリ骨子

## 1. 背景と目的

その日にやることを頭の中だけで整理するのは、誰にとっても難しい。多動傾向や ADHD のある人にとってはなおさらで、「やることが多すぎて手が止まる」「順番が決められない」「昨日の残りが積み上がって圧迫感になる」が日常的に起きる。

**みちしき** は、そうした人が「きょうの自分も、ちゃんと歩けた」と思えるための道しるべになることを目的とする。主役は道ではなく、歩く本人である。高機能なタスク管理ツールとは張り合わない。覚える操作を最小限にし、置いた瞬間から見通しが立つことを価値にする。

## 2. コンセプト

> **ならべて、わけて、ひとつずつ。**

- **ならべる** — 一列に置いて、上下で順番を決める。それだけで「次にやること」が決まる
- **わける** — 4象限に置いて、いま手を付けるものと手放すものを見きわめる
- **ひとつずつ** — できたら小さく喜ぶ。全部できたら、静かに祝う。次の日には、できた分を手放す

## 3. ターゲットユーザー

- やることの整理が苦手で、リストが増えるほど動けなくなる人
- 多動傾向・ADHD のある大人。将来的には支援者と一緒に使う子ども
- 多機能なタスク管理アプリに挫折した人

## 4. 設計上の判断

| 論点 | 判断 | 理由 |
|---|---|---|
| データの置き場 | 端末の `localStorage` のみ。サーバー・DB なし | 公開や共有を望まない利用者が多い。運用コストもゼロにできる |
| クラウド連携 | 第1弾では見送り。JSON の書き出し・読み込みで持ち運ぶ | OAuth の審査・運用が重く、子どもはアカウントを持たない。反応を見てから判断する |
| 日付の扱い | 未完了だけ翌日に持ち越す。履歴は持たない | 残り物が積み上がる圧迫感を避ける。「きょう」に集中する |
| 2つのモードの関係 | 同じタスクを、一列でも4象限でも見る | 4象限で決めた位置から一列の順番を提案できる。逆も成り立つ |
| 言葉 | 大人向けの、やわらかい表現 | 「緊急・重要」の硬さを避け、「いま、やる」「手ばなす」で伝える |
| 達成演出 | 完了ごとにひとこと＋小さな粒。全部できたら祝福表示 | Asana の完了体験にならう。集中を妨げない範囲での「ご褒美感」 |
| 辞書 | 家事・育児中心の言葉を「いつ」×「なに」のタグで持つ。入力の手間を減らす | 打つのが面倒で続かない、を避ける |
| くらしのかたち | こども・パートナー・家族・ペットの有無と名前で辞書を変える2段構え | 夫の項目が要らない人、同居の母を気にかける人、ペットの名前で呼びたい人、子どもが複数いる人、それぞれに合う |
| いつものセット | きょうの一覧を名前と曜日つきで保存し、朝に自動で置く | テンプレート編集画面を作り込まず、「作ってから保存」の一手で済ませる |
| 印刷 | 対応しない | Web での利用に集中する |
| 配色 | やわらかい 5 テーマ × 明暗 | 自分に合う色を選べることが、使い続ける動機になる |

## 5. 画面構成

1画面完結。上に「きょうの状況」、中央に表示の切りかえと本体、下に固定の入力欄。

```
┌──────────────────────────────┐
│ ／ みちしき                 ⚙ │
│ きょうのあなたもちゃんと歩けるように │
│ 9月5日 土曜日          ◯ 1/7  │
│ あと 6 件。                   │
│ [ならべる | わける]  4象限の順に │
│ ┌──────────────────────────┐ │
│ │ ◯ 先生に相談メールを送る ↑↓ │ │
│ │ ◯ 散歩 20分            ↑↓ │ │
│ └──────────────────────────┘ │
│ できた 1 ──────────────────── │
│ ( きょう、やることをひとつ   ⊕ ) │
└──────────────────────────────┘
```

「わける」では、まだ分けていないものを上のトレイに出し、その下に 2×2 の象限を置く。スマホはタップで置き場所を選び、PC はドラッグでも動かせる。

## 6. 技術構成

**「HTML・CSS・JS のみ、ビルド不要、サーバー不要」。そらみちと同じ構成。**

| 要素 | 採用 | 費用 |
|---|---|---|
| 本体 | 素の HTML / CSS / JavaScript | 無料 |
| 保存 | `localStorage` + JSON ファイルの書き出し・読み込み | 無料 |
| 書体 | Zen Maru Gothic（Google Fonts）、読み込めなければ端末のフォント | 無料 |
| オフライン | Service Worker で本体をキャッシュ | 無料 |
| ホスティング | Cloudflare（Workers 静的アセット / Pages） | 無料 |

## 7. 将来の拡張候補（必要になったら足す）

- 端末間の持ち運びを楽にする QR コードでの受け渡し（サーバー不要）
- 合言葉つきの暗号化同期（Cloudflare KV / R2）— 「データベースを持たない」思想との折り合いを見て判断
- 子ども向け表記（ひらがな中心・大きな文字）の切りかえ
- 一列表示でのドラッグによる並べかえ
- 「きめて、やる」に時間の目安を添える
