# みちしき — きょうのあなたもちゃんと歩けるように

その日にやることを **ならべて、わけて、ひとつずつ片づける** ための自己整理アプリです。
やることの整理が苦手な人（多動傾向・ADHD の方を含む）が、迷わずに使えることを第一に考えています。

- 📝 **ならべる** — やることを一列に置き、上下の矢印で順番を決める
- 📖 **よく使うことば** — 家のこと・子どものことを中心にした辞書。「いつ」×「なに」のグループで絞って、タップで置く。自分の言葉も足せる
- 🏠 **くらしのかたち** — こども・パートナー・同居の家族・ペットの有無と名前を登録すると、辞書が「はなの検温」「まるの散歩」のように、その家の言葉になる
- 🧭 **わける** — 「いそぐ／いそがない」「だいじ／だいじではない」の4象限に置いて、いま手を付けるものを見きわめる
- 🔁 **4象限の順にならべる** — 分けた位置から、一列の順番を組みなおす
- ✅ **できたら、ちいさな演出** — 完了ごとにひとこと。全部できたら、静かな祝福表示
- 🌅 **日付が変わると、できた分は手放す** — まだの分だけを翌日に持ち越す。積み上がらない
- 🎨 **5つの色のテーマ** — あい・あさやけ・わかば・ゆうなぎ・こはく。それぞれ明るい／暗い外観に対応
- 🔒 **データは端末の中だけ** — サーバーもデータベースも使わない。JSON ファイルへの書き出し・読み込みで自分で持ち運ぶ
- 📱 **PWA 対応** — スマホのホーム画面に追加して、オフラインでも起動できる

## 使い方

### いますぐ試す（ローカル）

リポジトリ一式をダウンロードして展開し、フォルダをローカルの静的サーバーで配信します（`index.html` を直接開いても動きますが、Service Worker は http(s) 配信時だけ有効になります）。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

ビルドもインストールも不要です。外部ライブラリは使っていません。

### 公開する（Cloudflare）

リポジトリに Workers 用の設定（`wrangler.jsonc`）を同梱しているので、Git 連携で接続するだけで公開できます。

1. Cloudflare ダッシュボードで **Workers & Pages → Create → Import a repository** を選び、`h-suwa39/michishiki` を接続する
2. Project name は `michishiki`、Build command は空、Deploy command は `npx wrangler deploy` のまま **Deploy**
3. `https://michishiki.<アカウント名>.workers.dev/` で公開される。スマホのブラウザから開き「ホーム画面に追加」でアプリのように使える

Pages で公開する場合は、Framework preset を None、Build output directory を `/` にすれば同じように動きます。

## 画面のことば

| 象限 | 意味 |
|---|---|
| いま、やる | いそぐ・だいじ |
| きめて、やる | いそがない・だいじ（時間を決めて取り組む） |
| さっと片づける | いそぐ・だいじではない |
| 手ばなす | いそがない・だいじではない |

「緊急・重要」のような硬い言葉を避け、やわらかい表現で統一しています。

## 辞書のしくみ

辞書の言葉は `js/app.js` の `DICTIONARY` にあります。ひとつの言葉に「いつ」（あさ・ひる・よる・ときどき）と「なに」（こどもと・かぞく・ペット・ごはん・おうちのこと・じぶんのこと・おでかけ・手続き・れんらく）のタグを複数付けられます。

`{こども}` `{パートナー}` `{かぞく}` `{ペット}` を含む言葉はテンプレートです。設定の「くらしのかたち」で名前が登録されていれば人数分に展開し、登録が無ければ `fb` に書いた言葉（無ければ一般の呼び名）になります。該当する役割が「いない」設定のときは表示しません。

## データについて

- 保存先はブラウザの `localStorage`（キー: `michishiki.v1`）のみ
- ブラウザのサイトデータを消すと一緒に消えます。設定の「ファイルに書き出す」でバックアップできます
- 書き出した JSON は、別の端末の「ファイルから読み込む」で復元できます

## 技術構成

- HTML / CSS / JavaScript のみ。ビルド不要・ライブラリ不要・サーバー不要
- 見出しの書体に [Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)（Google Fonts）を使用。読み込めない環境では端末の丸ゴシック系、ゴシック系に順に落ちます
- Service Worker でアプリ本体をキャッシュ（オフライン起動）
- ホスティングは Cloudflare（Workers の静的アセット配信。Pages でも可）

設計の背景は [docs/CONCEPT.md](docs/CONCEPT.md)、変更点は [CHANGELOG.md](CHANGELOG.md) を参照してください。
